# Sponsor Prize Research — PayPal AI Hackathon (Devpost)

Sources: the hackathon Official Rules (Section 8, Prizes), each sponsor's detail page under paypalaihackathon.devpost.com/details/…, and the sponsors' own sites. One cross-cutting rule that shapes the whole strategy, from the Rules: **a project can win at most one Grand Prize OR one Honorable Mention, plus at most one Sponsor Prize.** So even if Pact qualifies for several sponsor prizes, it can only collect one — pick the strongest fit to feature, and treat the rest as cheap insurance.

For reference, the full sponsor prize list in Section 8 is: AG Grid ($5,000 / $2,000 / $1,000 ×3), APIMatic ($1,000 ×3, plus subscription), Bryntum ($1,000 ×3), Channel3 ($1,500 ×1), Render ($1,000 / $750 / $500 in credits). No other sponsor has a judged prize — see section 5.

---

## 1. Channel3 — Best Use of Channel3, $1,500 (1 winner)

**What the product is.** A product-data API (YC S25 startup). One API call returns clean, normalized product data — titles, images, current prices, variants, availability, and buy links — across 100M+ products from 25,000+ retailers, searchable by text, image, or URL with filters (price, brand, category). It also ships Python/TypeScript SDKs and an MCP server. Normal pricing is 1,000 free searches, then $7 per 1,000; built-in affiliate commissions are their business model. It is built for shopping agents, gift finders, AI stylists, and product comparison tools.

**Exact requirement, in plain words.** From Channel3's hackathon page: your project must use the Channel3 API or its MCP server "as a meaningful part of the product experience — search, product enrichment or recommendations. Projects that only reference Channel3 without calling it will not meet this requirement." The Rules add only that the submission must "use any Channel3 tools." Access is friction-free: sign up at trychannel3.com/developers, no credit card, and promo code **PAYPAL-HACKATHON-2026** gives 20,000 free API credits (20,000 product searches); they promise Discord top-ups so credits never block a demo.

**Honest fit with Pact.** Real, but it needs one new scenario, not a bolt-on. Pact's current deals are over agent services with text deliverables; Channel3 sells retail product data. The genuine integration: add a procurement deal type where the buyer agent must acquire a real product. Channel3 search supplies the live market offers (what the product costs across retailers right now); the agents negotiate around that real market price instead of an invented one; the agreed item, SKU/title, and price ceiling become part of the frozen contract's acceptance checks; PayPal escrow, approval, and settlement work exactly as they do today. Channel3 becomes the market-data layer that grounds the negotiation in real prices — which is squarely Channel3's flagship "shopping agent" use case, and PayPal's own inspiration list for this hackathon names "an AI agent that shops and checks out for you." Anything shallower (e.g., a decorative product search box unrelated to the deal) would violate both the letter of their requirement and the honesty bar.

**Effort.** Low to moderate. One REST or MCP integration for search, one new deal scenario, contract checks derived from the returned product fields. A day of work, well inside the free credits.

**Verdict: Worth it.** It is the most natural second sponsor after AG Grid for an agent-commerce app, the requirement is explicit and easy to satisfy honestly, and a Channel3 founding engineer sits on the judging panel. The one caution: it is a single-winner prize, and the scenario must be a real deal flow, not set dressing.

## 2. APIMatic — Best Use of APIMatic, $1,000 + 6 months of APIMatic Business subscription (3 winners)

**What the product is.** APIMatic turns an API contract (OpenAPI and other formats) into production SDKs (Python, TypeScript, Java, C#, PHP, Ruby, Go), a hosted developer portal with API reference, playground and code samples, and — their newest line — "Context Plugins" that feed API knowledge to AI coding agents (Claude Code and similar) so the agent writes correct integration code. PayPal itself is an APIMatic customer.

**Exact requirement, in plain words.** The Rules state only: eligible submissions are those that "use any APIMatic tools." APIMatic's own hackathon page frames their intended use more narrowly: "Build with APIMatic Context Plugins for PayPal" — i.e., use their Context Plugin in your coding agent while building your PayPal integration. Their subscription offer confirms that framing: participants who used the Context Plugin to build their PayPal integration get 1 month of APIMatic Basic free; winning teams that used the plugin get the 6 months of Business (which also covers SDKs and a docs portal for your own API). The page does not state that SDK generation alone qualifies or disqualifies — the only formal bar in the Rules is "use any APIMatic tools."

**Would generating an SDK/portal from Pact's OpenAPI count, and what would it take?** On the Rules' wording, yes: SDK generation and portal generation are core APIMatic tools. Technically it is easy. FastAPI already emits the spec at /openapi.json. APIMatic's flow is: import the spec (dashboard, CLI, or VS Code), pass their validation ("Fix My OpenAPI" flags spec errors), generate — their marketing claim is OpenAPI-to-portal-and-SDKs in about 60 seconds via the CLI quickstart. For Pact the realistic work is: export the spec, fix validation warnings (FastAPI specs usually need operation summaries/descriptions cleaned up), generate a Python (and/or TypeScript) SDK, commit it to the repo with a small example showing another agent driving a full Pact deal through the SDK, and link the hosted portal from the README. That last step matters: an SDK for Pact's own API is genuinely useful for an agent-commerce platform (other agents are the customers), so the integration is honest, not ceremonial. To be safe on sponsor intent, do both halves: also use the Context Plugin for one real remaining piece of PayPal work (e.g., adding webhook signature verification) and say so in the submission.

**Effort.** Low. Half a day including spec cleanup and a demo snippet.

**Verdict: Worth it.** Three winner slots (the joint-most of any sponsor prize), a low integration cost, and an APIMatic co-founder is on the judging panel. The only soft spot is the ambiguity between the Rules' broad "any APIMatic tools" and the sponsor page's Context Plugin emphasis — doing both removes the risk.

## 3. Bryntum — Best Use of Bryntum, $1,000 (3 winners)

**What the products are.** Commercial JavaScript UI components for anything with a time dimension: **Gantt** (tasks on a timeline with dependencies that auto-shift), **Scheduler** (events assigned to resources — people, rooms, equipment — with drag/drop/resize), and **Calendar** (day/week/month/agenda views). Licenses are commercial, starting around $600 per developer per component per Bryntum's own site.

**Exact requirement, in plain words.** The Rules: submissions that "use any Bryntum tools." Bryntum's hackathon page defines the prize as going to "the project that puts Gantt, Scheduler, and/or Calendar to the best use, whether that's the cleanest timeline, the smartest resource booking, or an agent that drives the schedule itself." Their suggested ideas include an agency delivery board (Gantt) where payment tranches are dependencies so a late PayPal payment visibly blocks the next phase, and an agent-driven rescheduler that moves or flags milestones when a payment fails, succeeds late, or is refunded.

**Honest fit with Pact.** Narrower than Channel3 or APIMatic, but there is one real fit: a **deal timeline view**. Render each deal as a Gantt project — negotiation, escrow hold, delivery window, verification, settlement as dependent phases — where the settlement phase is dependency-blocked until verification passes, and a refund/slash visibly breaks the chain and reschedules the payout phase. That is truthful (it is a direct visualization of Pact's actual state machine and timestamps) and it matches two of Bryntum's own suggested ideas. What would not be honest: a generic project-management Gantt bolted onto the side that has nothing to do with deals. Note also that adding Bryntum Gantt alongside the existing AG Grid ledger means two commercial component libraries in one UI — defensible if the Gantt is a distinct timeline view, but it dilutes the AG Grid story slightly.

**Licensing/trial constraints.** Bryntum offers a 45-day free trial (download from bryntum.com or npm trial packages, e.g. `@bryntum/scheduler` via the `@bryntum/scheduler-trial` alias, no login needed for npm trials). The Rules require entrants to be authorized to use third-party tools per their license terms; a trial used within its window satisfies that for the hackathon. Two practical traps: (1) timing — a 45-day trial started October 22 expires around December 6, mid-judging (judging runs Dec 1–15), which could leave judges with a dead hosted demo; start the trial in early November so it covers the Nov 12 deadline and the full judging window. (2) The public repo — the trial packages are publicly distributed via npm, so referencing them is fine, but there is no open-source license for Bryntum itself; beyond the trial, any continued public deployment needs a paid license (~$600/dev).

**Effort.** Moderate. Embedding a vanilla-JS Gantt in the static UI, a read API that emits deal phases and dependencies, and keeping it live through judging. Figure one to two days.

**Verdict: Stretch.** A genuine fit exists (the deal-lifecycle Gantt) and there are 3 winner slots, but it is the weakest thematic match of the four, it adds a second commercial UI library next to AG Grid, and the trial-expiry-during-judging risk needs managing. Do it only after Channel3 and APIMatic are in, and only as the dependency-driven deal timeline, not a generic planner.

## 4. Render — Best Use of Render, 1st $1,000 / 2nd $750 / 3rd $500, all in Render credits (3 winners)

**What the product is.** A cloud hosting platform: web services, databases, background workers, and Render Workflows, an orchestration engine for distributed tasks and agent pipelines.

**Exact requirement, in plain words.** The Rules require only that the submission "use any Render tools." Render's hackathon page says: "Deploy your project on Render and use Render Workflows … to coordinate AI agents, background jobs, and data pipelines." The Workflows sentence is written as guidance on how to use Render, not as a stated eligibility condition — no page I found makes Workflows a hard requirement. Separately, every participant can claim **$50 in free Render credits** through the link on Render's hackathon page, win or lose.

**Fit and effort.** Pact already ships a render.yaml and its hosting target is Render, so eligibility is effectively already satisfied by deploying — near-zero incremental effort. To actually compete for 1st place rather than merely qualify, the sponsor's own page points the way: move one real piece of the deal lifecycle (e.g., the negotiation → verification → settlement pipeline, or the ledger event processing) into Render Workflows as orchestrated tasks. That is a moderate refactor, not a rewrite, and it is honest because the pipeline genuinely is a multi-step distributed process. Note the prize is credits, not cash — worth $1,000 only if the project keeps running on Render.

**Verdict: Worth it (the deployment alone).** It costs almost nothing since deployment on Render is already the plan, and it is the only sponsor prize Pact can qualify for by doing something it was going to do anyway. The Workflows upgrade is a stretch goal for 1st place if time remains after Channel3 and APIMatic.

## 5. Other sponsors — no judged prize in the Rules

Section 8 lists sponsor prizes only for AG Grid, APIMatic, Bryntum, Channel3, and Render. The remaining five sponsors appear as tool providers with participant perks only; none of their hackathon pages states a prize:

- **Astropods** — an "agent operating system" for running AI agents in production (models, knowledge bases, tool integrations, observability, guardrails); free account signup. No prize listed.
- **Elastic** — Elasticsearch (search/vector retrieval, Agent Builder, MCP/A2A connectivity). Perk: 14-day cloud trial, self-extendable by 30 days, or run it locally free. No prize listed. (A ledger-search integration would be thematically fine but wins nothing.)
- **KERNEL** — cloud browser infrastructure for agents (fast browser spin-up, persistent authenticated sessions). Perk: $50 in credits for hackathon participants. No prize listed. Not relevant to Pact, and its anti-detection positioning is best kept away from a payments project anyway.
- **Postman** — API design/testing/documentation platform; their page just links the free tier and PayPal's public Postman collections. No prize listed.
- **Zapier** — Zapier MCP, letting AI tools act across 9,000+ apps including PayPal. Perk: new accounts get a 14-day Professional trial, then drop to the free plan. No prize listed.

Also worth restating for strategy: AG Grid remains the richest sponsor pool ($5,000 + $2,000 + $1,000×3 = $10,000 across five winners) and Pact already uses it for the audit ledger — it is the sponsor prize to lead with, with Channel3 and APIMatic as the best-value additions, Render qualifying almost for free, and Bryntum as the optional stretch. And because the Rules cap a project at one Sponsor Prize total, these are ranked bets, not a stack.
